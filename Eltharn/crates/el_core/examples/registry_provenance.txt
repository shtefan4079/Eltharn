Eltharn built-in behavior tables

Behavior/data version: Java 26.2. Wire identifiers remain owned by the selected
versioned protocol backend; generating these tables does not select a wire version.

Generator: cargo run -p el_core --example regenerate_vanilla_tables -- INPUT_DIR OUTPUT_DIR [--check]
The normal product build consumes checked-in Rust tables. CSV, JSON tag inputs,
SNBT fixtures and oracle/test directories are not product build or runtime inputs.
Regeneration is an explicit maintenance operation and requires the complete input
corpus. --check compares generated bytes without replacing checked-in outputs.

Registry reports: block_states (32366), blocks (1196), items (1537), entities (158),
biomes (66). Sources: Java data reports BlockListReport/RegistryDumpReport and
BuiltInRegistries. Preserve registry row order and state/block identity.

Block mining/tool components: initialized BlockBehaviour.BlockStateBase values
(getDestroySpeed, requiresCorrectToolForDrops, render shape, offsets, getSeed)
and Tool rules/defaultMiningSpeed, including direct and nested tag selectors.
Lighting: BlockStateBase lightEmission, emissiveRendering, solidRender, light
dampening, isViewBlocking and getShadeBrightness, keyed by all 32366 state IDs.
Fluid support: isSolid, blocksMotion, six FULL isFaceSturdy faces, half-transparent/
leaves overlay classification and the IceBlock exception, in Java direction order.
Sound: SoundType volume/pitch and break/step/place/hit/fall event order.
Tags: 265 VanillaBlockTagsProvider JSON inputs, recursively resolved as holder sets.
Flammability: pinned 330-row static extraction of Blocks/FireBlock/DyeColor chains.
The known omission of sixteen ignited-by-lava wall banners remains unchanged;
data conversion is not evidence that this historical parity gap was corrected.
